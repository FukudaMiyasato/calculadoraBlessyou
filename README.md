# calculadoraBlessyou

Calculadora de un solo archivo (`index.html`) con panel de total y operaciones de suma/resta sobre montos predefinidos.

## Uso

Abre `index.html` en el navegador.

- El panel superior muestra el total acumulado.
- Botones **+** / **−**: solo esas dos operaciones (el **+** está activo por defecto).
- Botones de montos: `1, 2, 3, 4, 5, 6, 7, 10, 12, 16, 17, 19, 24, 28, 32, 34, 53, 57, 192`. Al presionar uno, suma o resta al total según la operación activa.
- **Limpiar**: reinicia el total a 0.
